 استخدام توسعه‌دهنده بک‌اند پایتون (Mid-Level)

برای تکمیل تیم فنی، به دنبال یک Python Backend Developer با تجربه در توسعه API و معماری Microservices هستیم.

مهارت‌های موردنیاز:

    ۲ تا ۴ سال تجربه توسعه بک‌اند با Python

    تسلط به FastAPI، Async و Pydantic

    تجربه کار با PostgreSQL، SQLAlchemy و Alembic

    آشنایی با Redis، Kafka و REST API

    تسلط به Git، Docker و pytest

    آشنایی با JWT، OAuth2 و اصول معماری نرم‌افزار

مزیت محسوب می‌شود:

    تجربه Temporal، Elasticsearch و ابزارهای مانیتورینگ

    آشنایی با سیستم‌های فروشگاهی و پرداخت

انتظارات ما:

    توانایی توسعه مستقل فیچرها و رفع باگ

    اهمیت دادن به کیفیت کد، تست و مستندسازی

    روحیه کار تیمی، مسئولیت‌پذیری و حل مسئله

    امکان دور کاری وجود ندارد.

معرفی شرکت

فعال در حوزه خدمات مالی و بانکی، با هدف توسعه راهکارهای نوآورانه و هوشمند، به دنبال جذب نیروهای مستعد و خلاق در حوزه برنامه‌نویسی و فناوری اطلاعات است. ما با فراهم کردن محیط کاری پویا، فرصت رشد و یادگیری، حقوق و مزایای مناسب، تسهیلات وام، امکان ادامه تحصیل، صبحانه و ناهار و ساعات کاری منعطف، از افراد توانمند و علاقه‌مند به فناوری و هوش مصنوعی برای همکاری و توسعه پروژه‌های فناورانه دعوت می‌کنیم.
